# 代码视频提示词模式库

用途：把用户的一句话扩写成 `motion-brief.json`，或在用户要“提示词/模板”时给出可复制的导演信。模板为本 skill 原创改写，机制来源在每节末尾注明；不要整段转载他人原文。

## 一句话扩写规则

用户只给一句话时（“做一个 15 秒的动态设计 showreel”“用 JS 做个视频讲 Transformer”），不要回问已有安全默认值的问题，按下面顺序自行补全：

1. **片型 → style**：产品/发布 → `product-promo`；UI/交互 → `ui-morph-loop`；作品集/炫技 → `showreel`；讲概念且要手绘 → `line-art-explainer`；有歌 → `lyric-mv`；像素/游戏 → `pixel-art`；历史/场景/3D → `cinematic-3d`。
2. **时长与画幅**：社交平台 9:16，官网/发布 16:9，UI 循环 1:1；没说时长用 style 默认值。
3. **一句话定调 + 3 条以上 Banned**：从 style 默认值出发，按题材增删。
4. **结构**：有音乐按小节写；无音乐按“钩子 → 展开 → 高潮 → 收束”写，每 2–4 秒一个可见变化。
5. **真实素材缺口**：品牌名、产品截图、授权音乐缺失时——一句话 autopilot 模式下用中性文字与几何代替并在交付中说明；`ask` 模式下写进 `inputs.missing` 先问。
6. **结尾**：乔木品牌内容按 `brand-card-templates.md` 加片尾；为第三方做的片子只放对方品牌。

## 模板 A：高端极简产品片（16:9，约 20 秒）

```text
<inputs>先问我：产品名和一句话承诺；3–5 个要展示的真实 UI 时刻；一种强调色；我拥有的真实截图或竖版片段；一首有明显 drop、可商用的歌（可选）。</inputs>
<direction>高端极简。一个镜头一个想法，大量留白，一种强调色，一种干净无衬线字体、紧字距。遮罩式文字揭示、匹配剪辑、统一的镜头语言。只用真实素材，不用占位卡片。
Banned：冲击波环、粒子爆炸、RGB 分离、镜头抖动、镜头光晕、霓虹辉光、网格地板、闪烁背景、弹跳缓动。</direction>
<structure>120 BPM，10 小节，每小节 2 秒。第 1 小节钩子逐词落在拍上；第 2 小节钩子里的一个词变形成产品 UI，光标输入并点击；drop 时从按钮里展开一个圆进入深色场景；之后每小节一个动作：关键输出大字、真实作品墙与扫描线、英雄镜头、推切大数字、三词字幕条、Logo、淡出。</structure>
<build>单个 HTML，所有样式在 seek(t) 内由时间计算；真实视频抽成 30fps JPEG 序列、seek 等待解码；分析歌曲得到节拍网格并校准到真实鼓点，切点在强拍、UI 命中在拍点；每帧 3 个子帧混合出动态模糊；音效按实测峰值对齐，压在音乐下，响度 −14 LUFS；整片渲染前抽查 20 帧以上。</build>
<gotchas>不要给 preserve-3d 元素设 opacity/filter，淡出其外层；匹配剪辑的位置在运行时测量；只用许可允许商用的音乐与音效。</gotchas>
<start>先问 inputs，再给我一份每个时间点都落在节拍网格上的分镜，确认后再写代码。</start>
```

对应命令：`qcut motion init <p> --style product-promo --audio assets/song.mp3`。
机制来源：zero (@twoclipping) 公开的产品片与 UI 循环模板；Danny Stuart 的“先分镜再编码”。

## 模板 B：UI 形态变换无缝循环（1:1，14 秒）

```text
<direction>Dribbble 级 UI 动效。只有一个形状、从不硬切：每个状态都是同一个元素改变尺寸、圆角和颜色，内容用短模糊交换。光标通过真实点击和拖拽驱动每次变化。浅暖灰画布、黑白组件、一种 UI 字体。处处弹簧，最多一点点过冲。镜头缩放让每个状态填满画面。最后一帧就是第一帧。
Banned：弹跳缓动、粒子爆炸、辉光、UI 外框渐变、图标描边不一致、死时间、模板感。</direction>
<structure>120 BPM、7 小节、每一拍都有事：按钮 → 加载 → 对勾 → 灵动岛 → 播放器（播放/暂停形变）→ 拖动进度条 → 变成音量滑块、拖过最大值时被拉长 → 开关在拍点翻转 → 旋钮变成液态标签指示器 → 标签展开成自绘图表并悬停提示 → 收拢成 ⌘K → 输入过滤 → 回车 → toast → 回到按钮。</structure>
<build>弹簧用闭式阶跃响应，多次改目标就叠加多个弹簧；标签指示器左右两边用不同弹簧，前缘先伸长；拖拽时值由光标位置计算，松手从当时位置弹回；每拍先渲一帧检查。</build>
<gotchas>不要在被镜头缩放的元素上用 will-change；首尾帧的光标位置和速度都要一致，否则循环会卡顿。</gotchas>
```

对应命令：`qcut motion init <p> --style ui-morph-loop --loop`；probe 会检查首尾接缝。
机制来源：zero (@twoclipping) UI 形态变换循环模板。

## 模板 C：结构化 30 秒讲解片（任意业务）

```text
扮演资深动态设计师，为我的业务做一支 30 秒动画讲解片，单个 HTML。5 个场景：客户的问题、我做什么、三步说明怎么用、一个证据、最后是我的名字。粗体字、顺滑转场、使用我的品牌色。我的业务：[卖什么、给谁、品牌色]。
```

迭代规则：一次只提一条修改（“慢一点”“更有活力”“加一个讲价格的场景”），只改对应镜头。
机制来源：Alex Prompter 的 5 场景讲解模板。

## 模板 D：线稿科普 / 口播改线稿

```text
做一个动画讲解「知识点」。风格轻松有趣，线稿动画，配合适的音乐，务必引人入胜。字幕中英双语，解说用 TTS（向阳乔木 v1.1），最终视频直接导出。
```

```text
把 input.mp4 做成新的竖屏短片：
1. 我的人像缩小成右下角圆形画中画，看得清我在讲话、不遮字幕；
2. 主画面换成跟随讲述内容的线稿动画 B-roll：我说到哪个概念，画面就画哪个概念；
3. 原声、原字幕、时长都不变。
```

落地：第一条走 `explainer-social` 旁白管线 + `line-art-explainer` 场景；第二条走 `talking-head`：ASR 字幕切镜头 → 每段一个线稿场景 → timeline 叠加圆形画中画。
机制来源：WY (@akokoi1) 的线稿科普一句话提示词；Axton (@AxtonLiu) 的口播转线稿三条约束。

## 模板 E：代码电影（历史/叙事，4–5 分钟）

```text
用代码完整制作一部关于「事件」的 4–5 分钟电影。先彻底研究，再自己决定怎么讲故事、怎么安排节奏、怎么解释策略和呈现事件。要求史实准确、有戏剧性、易懂、视觉出众。附件画作只是灵感，不是硬性风格：我喜欢它们的尺度、氛围、烟雾、天空和混乱感——把这种感觉翻译成代码；如果你能发明更强的视觉语言就去做。
不要做成普通信息图或策略游戏，要像一部恰好用代码渲染的历史电影。你有完全的创作控制权，给我惊喜。
```

落地：`cinematic-3d` style；研究结论写入 claims 并保留来源；旁白走 ListenHub；长片按幕拆成多个 motion 项目再进 timeline。
机制来源：Winter (@WinterArc2125) 的奥斯特里茨战役提示词（开源仓库 Battle-of-Austerlitz-Film）。

## 模板 F：规格型提示词（像素/程序化角色）

写法：RENDERING（逻辑分辨率、整数放大、调色板）→ CHARACTER（程序化绘制、参数化姿态、量化到网格）→ ANIMATION（状态机、无分配粒子池、固定时间步）→ SCENE（极简背景、轮廓可读）→ QUALITY BAR（清晰像素、无缝循环、像精致 16-bit 精灵而不是缩小的矢量）。
注意：原案例用固定 60Hz 步进和 rAF；在 qiaocut 中改写为由 t 直接推导状态机阶段与粒子位置（粒子 i 的轨迹 = f(t − 发射时间, random(i))），否则无法逐帧确定性渲染。
机制来源：Majid Manzarpour 像素巫师；Rikuo 彩虹路规格型提示词。

## 模板 G：歌词 MV

```text
为这首歌（我有使用权）做竖屏歌词 MV。歌词本身是主角：大字动态排版，节奏跟随人声；开头两秒内给一个强视觉钩子；副歌给全片最大的视觉想法；器乐段也要有事情发生。先分析歌曲得到节拍和段落，把每句歌词的出现时间对齐到人声起点，给我看分镜后再写代码。完成后反复完整观看、截图、对照标准返工。
```

落地：`lyric-mv` style；`qcut audio beats` + 本地 ASR 取人声时间；歌词时间写入 storyboard events。
机制来源：P(doom) MV（p5.js 逐帧，仓库含 ANIMATION_GUIDE.md）、Linux.do《Let Me Go》MV、donald 的混合流程 MV（视频模型底片 + JS 逐帧重绘）。

## 一句话也能出片的参考

这些极短提示在高推理强度下能出片，但质量波动大；qiaocut 的做法是先把它们扩写成 brief 再执行：

- “为一家做推理的初创公司做一个现代、利落、有冲击力的视频”（Deedy）
- “做一个 15 秒的动态图形视频，像简历里的 showreel 一样展示你是多厉害的动态设计师，全力以赴”（Stephan Livera，Max effort）
- “做一段动画：从房间推进到 MacBook，再进入芯片、原子，最后到夸克”（Taelin，多尺度连续推镜）
